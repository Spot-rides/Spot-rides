# Frontend Skill

## Purpose
Implement an Expo/React Native feature from a task definition.

## Steps

1. Read task from `docs/plans/`.
2. Create screen file in `frontend/screens/<FeatureName>Screen.tsx`.
3. Create reusable components in `frontend/components/`.
4. Wire navigation in the appropriate navigator.
5. Integrate API calls using the backend base URL from env/config.
6. Handle loading, error, and empty states.
7. Write Jest tests alongside the component.
