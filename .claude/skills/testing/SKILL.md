# Testing Skill

## Purpose
Ensure a feature is fully tested before review.

## Steps

1. Read implementation diff and plan tasks.
2. Identify test cases: happy path, edge cases, error paths.
3. Backend: write pytest tests using `pytest-django` fixtures.
4. Frontend: write Jest + RNTL tests for each component and screen.
5. Run full test suite; fix failures before proceeding.
6. Report coverage; flag any lines below threshold.
