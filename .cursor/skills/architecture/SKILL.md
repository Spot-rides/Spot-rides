# Architecture Skill

## Purpose
Translate requirements into a technical design ready for implementation.

## Steps

1. Read the requirement doc from `docs/requirements/`.
2. Identify components: new models, API endpoints, UI screens, integrations.
3. Draw system boundary diagram (ASCII or Mermaid).
4. Define data models and API contracts.
5. Document trade-offs considered.
6. Validate against `schemas/architecture.schema.yaml`.
7. Save ADR to `docs/decisions/YYYY-MM-DD-<slug>.md` and design to `docs/architecture/`.
