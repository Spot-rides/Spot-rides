# Requirements Skill

## Purpose
Produce a well-structured requirement document from a raw feature request.

## Steps

1. Ask clarifying questions to resolve ambiguity.
2. Identify stakeholders and user personas affected.
3. Write user stories: `As a <persona>, I want <goal>, so that <benefit>.`
4. Define acceptance criteria (Given/When/Then format).
5. List out-of-scope items explicitly.
6. Validate against `schemas/requirement.schema.yaml`.
7. Save to `docs/requirements/YYYY-MM-DD-<slug>.md`.
