AI-assisted development workspace for the Spot Rides project.

| Path | Purpose |
|------|---------|

| `schemas/` | YAML schemas for structured outputs |
| `templates/` | Document templates |
| `docs/` | Living project documentation |
| `.ai/` | AI runtime config and state |
